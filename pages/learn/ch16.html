Allocation of Support-Department Costs, Common Costs, and Revenues

Compare direct, step-down, and reciprocal allocation methods for support departments, allocate common costs fairly, and distribute bundled revenues using standalone, incremental, and Shapley value approaches.

Learning Objectives

  1. Identify the purposes of allocating support-department costs to operating departments
  2. Distinguish between the direct, step-down, and reciprocal allocation methods
  3. Allocate support-department costs using all three methods and explain the differences
  4. Allocate common costs using the standalone and incremental methods
  5. Allocate revenues from bundled products using standalone, incremental, and Shapley value methods

Tool 2 of 4

Common Cost Allocator

A common cost is the cost of operating a facility shared by two or more users. The standalone method allocates based on each user's proportional standalone cost. The incremental method assigns costs based on a primary/secondary ranking. Compare both methods and see how the choice affects each party.
