Process Costing

Track physical unit flows, compute equivalent units of production, and assign costs to completed units and ending work-in-process using both the weighted-average and FIFO methods.

Learning Objectives

  1. Identify the types of operations that use process costing systems
  2. Describe the five steps in process costing
  3. Calculate equivalent units of production under the weighted-average method
  4. Calculate equivalent units of production under the FIFO method
  5. Apply the five-step process costing procedure under both methods
  6. Understand how transferred-in costs affect process costing in subsequent departments
Tool 1 of 5

Physical Units Flow Tracker

Before any cost calculations, you must account for where every physical unit goes. Units to account for (beginning WIP + units started) must equal units accounted for (units completed + ending WIP). This is Step 1 of the five-step process costing procedure.

Tool 2 of 5

Equivalent Units Calculator

Equivalent units convert partially completed units into a whole-unit equivalent. The weighted-average method includes work done in prior periods on beginning WIP. The FIFO method counts only work done in the current period. Enter physical units and completion percentages to see Step 2 under both methods.

Tool 3 of 5

Weighted-Average Process Costing Engine

The weighted-average method blends prior-period and current-period costs together. It is simpler than FIFO because it treats all equivalent units the same regardless of when work was done. Enter costs and unit data to run all five steps.

Tool 4 of 5

FIFO Process Costing Engine

The FIFO method separates prior-period work from current-period work. Beginning WIP units are completed first using current-period costs for the remaining work. This produces a more accurate picture of current-period efficiency. Enter the same data as Tool 3 plus beginning WIP completion percentages.
