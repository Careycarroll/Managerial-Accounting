
# Managerial Accounting Interactive -- Agent Prompt

You are a code agent for the Managerial Accounting Interactive project. This is a Vite-based multi-page web application that teaches Horngren's Cost Accounting (17th Edition) through interactive tools.

---

## Project Context

Goal: Build a comprehensive interactive learning companion covering all 24 chapters of Horngren's Cost Accounting. Students learn concepts chapter by chapter (Learn section), then apply them to real business decisions (Apply section).

Live site: https://careycarroll.github.io/Managerial-Accounting/
Repo: ~/Github Projects/Managerial-Accounting/

### Key Patterns
- Vite multi-page -- vite.config.js auto-discovers all HTML files in pages/learn/ and pages/apply/
- Base path -- process.env.NODE_ENV === 'production' ? '/Managerial-Accounting/' : '/'
- Progress tracking -- js/core/progress-tracker.js uses localStorage. Import markChapterComplete, isChapterComplete, resetChapter, getProgress as needed.
- Randomizer -- js/components/randomizer.js. Call initRandomizer(buttonId, fields, onRandomize?) on numeric tools.
- Show Work -- js/components/show-work.js. Call renderShowWork(containerEl, steps, options) after calculation output is rendered.
- Journal Entry -- js/components/journal-entry.js. Call renderJournalEntry(containerEl, entries, options) when accounting entries are needed.
- Settings Panel -- js/components/settings-panel.js. Call initSettingsPanel() inside DOMContentLoaded on every chapter page. Injects gear button into header nav, manages width/font/theme preferences via localStorage.
- Canvas charts -- chart-core.js provides the base chart layer; cvp-chart.js, scatter-chart.js, roc-chart.js, and pareto-chart.js are built chart components.
- Full-bleed layout -- .full-bleed class in components.css for elements that need to break out of container--tool width.
- Cross-page data sharing -- use sessionStorage to pass calculated results between chapter pages where needed, such as Ch. 7 to Ch. 8.
- Chapter nav -- every built chapter page should include All Chapters, previous chapter, chapter position, and next chapter links in the hero nav.
- KaTeX -- installed as a dependency for formula rendering across chapter tools.

### CSS Design System
All custom properties defined in css/base.css:
- Colors: --color-primary (#1a365d navy), --color-primary-text (#1a365d light mode / #90cdf4 dark mode), --color-accent (#c8973a gold), semantic colors (success/warning/danger/info), gray scale
- Depth colors: --color-concept (blue), --color-analysis (green), --color-simulation (purple)
- Spacing: --space-1 through --space-16
- Typography: --font-sans (Inter), --font-mono (JetBrains Mono), --font-size-xs through --font-size-4xl

- Max widths: --max-width-tool (adjustable via settings panel, default 1100px), --max-width-content, --max-width-narrow

## Dark Mode Rules

Dark mode is toggled via data-theme="dark" on the html element. All dark mode overrides live in css/settings-panel.css.

### Critical Rule: No Hardcoded Hex in JS Output
Never use hardcoded hex color values in JS-generated HTML. Always use CSS custom property references so dark mode works automatically.

WRONG:
    background: '#f0fdf4'
    color: '#166534'
    border: '1px solid #22c55e'

RIGHT:
    background: 'var(--color-success-bg)'
    color: 'var(--color-success)'
    border: '1px solid var(--color-success)'

### Dark Mode Token Reference
Use these tokens in all JS-generated output HTML:

    Backgrounds:
    --color-success-bg     dark green  (#1a3a2a in dark)
    --color-danger-bg      dark red    (#3a1a1a in dark)
    --color-warning-bg     dark amber  (#3a2a00 in dark)
    --color-info-bg        dark navy   (#1a2a3a in dark)

    Text/borders:
    --color-success        teal        (#4fd1c5 in dark)
    --color-danger         red         (#fc8181 in dark)
    --color-warning        amber       (#f6ad55 in dark)
    --color-info           light blue  (#90cdf4 in dark)
    --color-primary-text   light blue  (#90cdf4 in dark, navy in light)
    --color-accent         gold        (#c8973a, same in both)

    Neutral:
    --color-gray-50 through --color-gray-900  (all overridden in dark)
    --color-border         dark border (#3d4f66 in dark)
    --color-card-bg        dark card   (#1e2530 in dark)

### Inline Script in Every HTML Head
Every chapter HTML must include this inline script before </head> to prevent flash of unstyled content:

    <script>
      (function(){
        var r = document.documentElement;
        var w = localStorage.getItem('pref-width');
        var f = localStorage.getItem('pref-font');
        var t = localStorage.getItem('pref-theme');
        if (w) r.style.setProperty('--max-width-tool', w + 'px');
        if (f) r.style.setProperty('--font-scale', f);
        if (t === 'dark') r.setAttribute('data-theme', 'dark');
      })();
    </script>

## Component Reference

### initSettingsPanel()
    Call inside DOMContentLoaded on every chapter page.
    Injects gear button into .site-header__nav.
    Manages --max-width-tool, --font-scale, and data-theme via localStorage.
    Keys: pref-width, pref-font, pref-theme.

### initRandomizer(buttonId, fields, onRandomize?)
    fields: [{ id, min, max, step, integer?, constraint? }]
    constraint: 'lessThan:otherId' or 'greaterThan:otherId'
    onRandomize: callback fired after all fields are set (use to trigger calculate)

### renderShowWork(containerEl, steps, options?)
    steps: [{ label, formula, values, result, highlight?, note?, step? }]
    options: { title, defaultOpen, id }
    highlight: true = amber background in dark mode, blue in light mode
    Always call after output is rendered, never before

### renderJournalEntry(containerEl, entries, options?)
    entries: [{ account, debit, credit, indent }]
    options: { title, subtitle, showTotals, balanced }

### ParetoChart(canvasEl, config)
    config: { data: [{ label, value }], title }
    chart.update(config) -- redraws with new data
    Used by Ch. 20 Tool 5.

### CVPChart(canvasEl, config)
    config: { sellingPrice, variableCost, fixedCosts, maxUnits, currentUnits? }
    chart.update(config) -- redraws with new config

### getOrCreate(id, tag, className, parent)
    let el = document.getElementById(id);
    if (!el) {
      el = document.createElement(tag || 'div');
      el.id = id;
      if (className) el.className = className;
      if (parent) parent.appendChild(el);
    }
    return el;

## Development Rules

Discovery first. Before touching unfamiliar files, run simple discovery commands. Never assume file contents.

Use simple zsh commands safe to paste into VS Code terminal. Use full paths. Avoid complex multi-line shell blocks. Avoid unescaped ! characters (zsh history expansion).

No hardcoded hex in JS output. Use CSS custom property tokens only. See Dark Mode Rules section above.

CSS writing rule. Write CSS as a Python list of strings joined with newline. Never use shell heredocs for CSS.

Kill dev server:
    lsof -ti :5173,:5174,:5175,:5176 | xargs kill -9 2>/dev/null; pkill -9 -f vite 2>/dev/null; echo done

Commit after each chapter or logical milestone:
    feat: Chapter N -- Title
    - pages/learn/chNN.html: what is in it
    - js/learn/chNN.js: tools built

Check for syntax errors before browser testing:
    node --input-type=module < js/learn/chXX.js 2>&1 | head -20
